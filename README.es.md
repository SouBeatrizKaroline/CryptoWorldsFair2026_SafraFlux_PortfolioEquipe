# SheBuilds — Ideas que echan raíces

[Português (Brasil)](README.pt-br.md) · [English](README.en.md) · [Español](README.es.md)

Portafolio del equipo SheBuilds y SafraFlux, disponible íntegramente en portugués de Brasil, inglés y español. La estructura, los hechos y los perfiles son equivalentes en las tres versiones; los botones, descripciones accesibles, metadatos y capturas siguen el idioma.

## Estructura

| Ruta | Descripción |
| --- | --- |
| src/index.template.pt-br.html | Plantilla de página compartida. |
| src/locales/*.json | 302 textos por idioma; mismas claves y orden. |
| src/style.css, src/app.js | Estilos e interacciones compartidos. |
| scripts/ | Generación y validación sin dependencias externas. |
| dist/ | Sitio estático generado, listo para publicar. |

## Editar y validar

Edite la plantilla y las tres traducciones juntas. Después genere el sitio y ejecute la verificación. No edite directamente las páginas generadas. La página inicial predeterminada es portugués de Brasil; las otras son index.en.html e index.es.html. Las rutas anteriores de la página inicial siguen funcionando.

```sh
npm run build
npm run check
```

## Publicar

La configuración Vercel usa npm run build y publica dist. Después de integrar el cambio en la rama principal, Vercel puede publicar automáticamente si el repositorio está conectado. No se necesitan claves de API.

## Fuentes y límites

El equipo trabaja remotamente en Brasil. Beatriz lidera producto y desarrollo; Sonia contribuye con análisis de producto y pitch; Olivia con estrategia y mercado. Los perfiles y la trayectoria previa fueron proporcionados por el equipo. Se relata una prueba externa de demo; no hay clientes de pago, ingresos ni pilotos comerciales confirmados.

Meteora es un laboratorio local, Panta espera validación con credenciales y Solami es un diagnóstico separado. La evidencia Zcash es regtest, sin valor monetario. La participación en categorías no equivale a premio ni elegibilidad confirmada. El proyecto principal es privado; su acceso requiere autorización.

Los monogramas representan a las creadoras sin fotos inventadas. Los logos son compartidos; la captura del producto tiene una versión por idioma. Se conserva la atribución de bibliotecas y asistencia técnica.
